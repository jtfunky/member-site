WHAT'S IN IT
------------------------------------------------------------------------
Auth & security     : registration, login, sessions/timeout, password
                      reset, rate-limiting/lockout, CSRF, CSP + security
                      headers, Google/Facebook OAuth
Membership/payments : enrollment, free-trial flow, proof-of-payment,
                      access gating, programs/pricing, IP-geo, profile
                      completion, Stripe scaffolding
Session scheduling  : calendar, booking/reschedule/cancel, credits,
                      top-ups, email notifications
Drum game           : canvas engine, timing/scoring/charts, MIDI input,
                      acoustic mic detection + per-kit calibration
                      (FFT/onset DSP), single-pad mode, audio sync, song
                      library, progress tracking, fullscreen/mobile
Chart Editor        : timeline recording, quantize, zoom/pan, undo,
                      box-select, MIDI pad mapping, audio BPM/onset detect
AI (Claude)         : placement test + coaching, 10-session plan
                      generation, coach edit UI
Admin panel         : users, students (CRUD/filters/bulk/payments),
                      sessions, songs, placement tests, plan editor
Plus                : full mobile-first responsive pass, email, uploads,
                      DB migrations, deployment

WHY IT LANDS HIGH
------------------------------------------------------------------------
The game engine, the acoustic mic DSP/calibration, and the chart editor
alone are ~200-310 hours of specialist real-time/audio work. That's the
part that commands premium rates and that most generalist developers
could not build quickly.

Strip those three specialized pieces out and you'd have a "normal"
membership site at maybe 350-500 hours.
